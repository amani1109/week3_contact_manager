# Contact Management System

A Python-based contact management system using dictionaries, functions, and file handling.

## Features
- Add, search, update, delete contacts
- Partial name and phone search
- Input validation
- JSON data persistence
- CSV export
- Contact statistics
- Backup system

## How to Run
bash
python contacts_manager.py

## File Structure
contacts_manager.py – Main application
contacts_data.json – Stored contact data
test_contacts.py – Unit test
